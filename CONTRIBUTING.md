# Contribuer

Sarielle Fashion est un **projet client** sous licence propriétaire (voir [LICENSE](LICENSE)). Les contributions externes ne sont pas attendues et les pull requests non sollicitées ne seront pas fusionnées.

- Une erreur dans la documentation ou un bug : ouvrez une issue (sans donnée personnelle ni secret).
- Une faille de sécurité : suivez [SECURITY.md](SECURITY.md), pas d'issue publique détaillée.

Pour le mainteneur : branches `feat|fix|refactor|chore|docs/<slug>`, jamais de commit direct sur `main`, `npm run ci` vert avant pull request, voir [docs/git.md](docs/git.md).
